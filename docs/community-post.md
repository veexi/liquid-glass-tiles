# English post

**Liquid Glass Tiles — a frosted glass wallpaper plugin for KDE Plasma 6**

I made a small native Plasma wallpaper plugin that brings rounded glass tiles to your own wallpaper. The glass becomes visible around the pointer and fades out toward the edges. You can adjust frost, refraction, opacity, tile size and the pointer radius. Pointer tracking has no added delay by default.

**The original visual concept is by Gábor Molnár / DesignGabor.** Thank you, Gábor, for the inspiration and for being happy to share this adaptation with the Linux community!

- Portfolio: https://avely.me/designgabor
- X: https://x.com/DesignGabor
- Original work: https://my.spline.design/glassmorphcursortracking-2ef6d3790000fd1a4f81c92fb3ff5bf5/

The plugin is free and open source (MIT), implemented with QML and shaders, with AI assistance. It runs locally and includes an original demo background. It doesn't need Python, a browser or a Spline account to run.

This is an early community release. Desktop pointer integration was tested on Plasma 6.7.3 / Wayland; other GPUs and multi-monitor setups are welcome test cases. Installation and removal use `kpackagetool6 --type Plasma/Wallpaper`.

Attach `preview.png`, `demo.mp4` and the release/download link when posting. No post has been published by this repository's build tools.

# 中文发布文案

**Liquid Glass Tiles：给 KDE Plasma 6 壁纸加上鼠标跟随的磨砂玻璃方格。**

圆角玻璃网格覆盖自己的壁纸，鼠标附近明显、外围渐变淡去。可以调整磨砂、折射、透明度、方块大小和鼠标范围，默认不额外添加跟随延迟。

- 原始作品：https://my.spline.design/glassmorphcursortracking-2ef6d3790000fd1a4f81c92fb3ff5bf5/
